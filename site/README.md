# CBE Thesis Explorer

Open [Website/index.html](Website/index.html) in Chrome. On macOS you can also use
[Open_Explorer.command](Website/Open_Explorer.command). Keep this folder together
when moving the app so the statement PDFs, datasets, and study files open.

Use **Walkthrough** for the six-step introduction. From Overview choose
**Trace 6 March 2024** to open the original statement, market closes, and saved
forecast rows. **Study files** opens the report, notebook, workbook, slides,
and supporting archive.
